# 党政机关公文格式检查要点

本规则来自 FastGPT 导出工作流“公文优化”的有效经验，但不照搬其内网 HTTP 检测节点。工作区实现采用“本地解析与确定性检查 -> 报告整理与优化建议”的 LangGraph 工作流。

## 参考标准

- 《党政机关公文格式》GB/T 9704-2012。
- 具体单位模板、发文机关要求和最新内部制度优先于通用检查规则。

## 第一版检查范围

- 文件是否可解析，是否存在可检查正文。
- DOCX 页面基础设置：A4 纸张、常用页边距。
- 标题、主送机关、正文、成文日期等基础结构。
- 标题与正文显式字体线索。
- 非 DOCX 输入只做文本结构检查，不声称已核验页边距、字体、印章、版记。

## 输出要求

- 按高、中、低和提示信息分组。
- 每条问题给出证据、影响和整改建议。
- 没有读取到的信息必须标为“无法核验”或“待补充资料”。
- 报告末尾必须说明：本报告为格式辅助检查，不替代单位公文审核流程。
