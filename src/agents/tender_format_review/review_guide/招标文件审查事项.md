# 招标文件修订经验指南（编写：陈泳吉）

## 制度依据补充

- 审查广西投资集团有限公司及其子公司、下属企业项目时，应同时使用同目录下的《广西投资集团采购管理办法审查依据.md》。
- 该依据来自《广西投资集团有限公司采购管理办法》（桂投发〔2023〕83号），重点补充采购方式、必须招标限额、集团/子公司/自行采购层级、电子采购平台、招标文件编制审查、程序时限、非招标采购、合同签订和付款归档等制度性检查项。
- 当待审招标文件缺少项目金额、采购类别、采购主体、采购方式或审批层级时，不要直接判定违规，应标注为“需跨章节复核”或“需人工确认”。

## 第一章 项目基本属性与规范
### 1. 标的类型影响矩阵
不同项目属性将直接影响招标文件的多项条款，修订前需首先明确：
| 标的类型 | 影响范围 | 具体影响内容 |
| :--- | :--- | :--- |
| **电子标 / 纸质标** | 投标方式与盖章 | 电子标通常无需现场投标；电子标承诺项等无需重复加盖公章，一般仅在封面盖电子章 |
| **服务类 / 货物类** | 税率与称呼 | 影响适用税率；影响合同甲乙双方规范称呼 |
| **是否要求源代码** | 承诺与交付节点 | 影响承诺函及承诺项内容；影响初验/终验的交付里程碑要求 |
| **是否分阶段** | 进度与计价 | 影响功能建设描述与时间节点、付款进度比例、验收节点及报价表设计 |
### 2. 称呼与规范要求
- **称呼红线**：200万以上必须公开招标的项目，严格使用 **“招标人/招标方”“投标人/投标方”“中标人”**；金额较小的采购项目，使用 **“采购人”和“供应商”**，绝不可混淆。
- **易混淆称呼**：谨慎使用“甲方/乙方”及“业主/用户/服务方”，需根据具体语境判断是否为正常混用，“甲方/乙方”可使用在合同相关内容中，不与称呼红线冲突。
- **招标编号**：由咨询公司确定，大部分代理商要求的内容也由咨询公司主导（尤其是集团内部咨询公司）。
- **排版预留**：大章节后留空白页是方便双面打印的正常现象，勿擅自删除。

## 第二章 商务与进度要求
### 1. 招标建设内容与工期（重点查重）
- **项目建设内容**：全文通常有**3处**需完全一致地修改，缺一不可。
- **工期表述**：正文有**2处**需完全一致修改；付款阶段的工期相关内容也需同步修改。
- **时间标准**：
  - 起始时间一般称**“合同签订之日起”**；若为“项目开工之日起”，必须明确开工之日的认定标准。
  - 建议使用**“个日历日”**代替“个月”（换算标准：1个月=30个日历日），避免歧义。
### 2. 付款与验收阶段逻辑
- **付款前提**：一般为“乙方”向“甲方”开具等额合法增值税专用发票后20个工作日内付款。
- **阶段划分与比例**：
  1. **预付款**：合同价的 **10%~20%**。
  2. **初验款**：主体功能开发→联调/整体测试→试运行（30~90个日历日）→申请初验。初验通过后支付 **50%~70%** 合同款。*(注：按项目情况确定初验是否需交付源代码)*
  3. **终验款**：初验后进入运行阶段→终验。终验不付全款，需开具剩余金额发票（如20%~50%），但**需扣留5%~10%作为质保金**，实际支付金额为开票金额减去质保金。
  4. **质保金**：一般为合同款的 **5%~10%**，质保期通常一年以上。
- **投标保证金**：不计入合同总价，不按照比例列明，以固定数额形式列明，实际数额可约为合同总价的 **2%**。
- **履约保证金**：不计入合同总价，一般为合同款的 **5%~10%**。
- **税率列明**：根据项目是否包含服务类或货物类，确认“合同金额和支付方式”条款中是否需分别列明服务类税率和货物类税率。
### 3. 报价表与项目进度
- 若每个报价项均只有一项，可删除“报价小计”列（此时与单价重复）。
- 合同附件《项目进度表》若描述为“根据投标响应列明”，则由投标人自行列明项目技术要求和计划完成工作。
### 4. 业绩要求
- **时间范围**：对公司业绩要求一般为三年内，按**“从XXXX年1月1日起至投标截止日”**计入。
- **相关性要求**：业绩必须能在投标内容中体现，不可与投标内容无关，否则易出问题。最好与招标平台提及的功能或名称相关。

## 第三章 技术与评分要求
### 1. 技术参数与演示
- **反指向性**：功能参数**不得有指向性**（排他性）。
- **演示标识**：用 **▲** 标识需招标时现场演示的功能。注意：需演示的功能必须具有**通用性**，难度不宜太高，确保参与投标的厂商均能演示。
### 2. 评分表设置要点
- **可核验性**：必须有明确的按项评审打分标准（哪项得几分、最高几分明确列出），避免主观描述。
- **字眼陷阱**：区分 **“具有”**和 **“每具有”**，按数量计分时一般用“每具有”。
- **主观分规避**：杜绝“综合评定优秀”等模糊表述，需划分等阶的按给分范围划分。
- **区间符号**：`（）`表示不包含本数，`【】`表示包含本数。一般不严格区分时，统一用`（）`并在备注列明“包含本数”即可。
- **证明材料**：
  - 电子标要求证书为**扫描件**而非复印件。
  - 项目团队成员的业绩一般只需提供 **“验收报告”**，无需合同等繁杂材料。
- **专利认定**：若未明确要求“发明专利”，则默认实用新型和发明专利均认可。

## 第四章 合规与法律条款
### 1. 承诺函与星号（★）条款
- **内容合并**：所有带星号（★）的实质性要求，必须放入承诺函中（价格部分承诺视格式而定，承诺函在第六章中，一般在第六章“第三部分 技术部分”）。
- **称呼转换**：承诺函中需将“投标人/中标人”等称呼统一改为**“我公司承诺”**格式。
- **联动修改**：承诺函与正文中带星号的内容，**两者修改时必须同步**，确保一致。
- **盖章简化（电子标）**：电子投标中，承诺项（带星号项）正文中“加盖公章”的要求可去掉，减少废标风险（电子标一般仅在封面加盖电子章）。
### 2. 违规与造假处罚
- 投标人成员资质与投标时不符（如伪造资质证书等弄虚作假行为），**不能简单以罚钱处理**，必须明确“根据集团制度进行相应的处置”，保留追诉权。
### 3. 知识产权约定
- 若有知识产权约定，需明确约定类型（如：是否为发明专利、论文发表分区等），避免后期纠纷。

## 第五章 特殊场景处理
### 1. 分阶段项目
- **报价限制**：需修改最高限价要求（如二阶段与一阶段报价不高于某比例）。
- **清单拆分**：明确功能清单中哪些属于一阶段，哪些属于二阶段。
- **表格调整**：报价表需增加分阶段列及合计计价行。
### 2. 源代码交付项目
- 在初验或终验节点，需增加源代码交付与审查的约束条款。
- 增加源代码版权及使用范围的承诺项。
