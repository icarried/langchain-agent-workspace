# 广西投资集团采购管理办法审查依据

来源依据：`广西投资集团有限公司采购管理办法`，桂投发〔2023〕83号，2023年3月20日印发，自董事会审议通过之日起执行。

用途：本文件不是制度全文转录，而是面向 `tender_format_review` 智能体的招标文件审查规则摘要。审查时应把下列规则作为集团制度依据，重点发现招标文件、采购文件、评审办法、合同条款、公告时限、供应商要求和审批流程中的缺漏、矛盾或高风险表述。

## 一、适用范围与平台要求

### 1. 适用对象

- 适用于广西投资集团有限公司、子公司及其下属企业在工程建设、生产经营等过程中的工程类、货物类、服务类项目境内采购及招投标活动。
- 对外承揽业务中与第三方合作、贸易业务中向上游采购的环节不适用；另有专项规定的遵循专项规定；涉及上市公司的，应在符合法律法规及监管规定前提下实施。
- 审查触发：招标文件若项目主体属于集团、子公司或下属企业，但未说明适用采购制度、审批层级、采购平台、归档或监督要求，应列为疑似缺漏。

### 2. 电子采购平台

- 合同估算价 5 万元及以上的项目，应使用广西投资集团电子采购平台实施采购；涉密项目及行政主管部门另有要求的除外。
- 未使用电子采购平台实施的项目，必须及时在系统补录相关信息。
- 通用、低值、易耗办公物资、通用工业品物资、协同产品，必须通过广易采供应链平台实施采购。
- 审查触发：文件中出现线下递交、纸质开标、线下评审、非平台发布公告等安排时，应核对是否说明涉密、主管部门另有要求或补录机制。

## 二、集中采购与采购层级

### 1. 集团集中采购阈值

达到以下任一条件的项目实行集团集中采购：

| 类别 | 集团集中采购阈值 |
| --- | ---: |
| 工程建设类 | 合同估算价 5000 万元及以上 |
| 货物类 | 合同估算价 3000 万元及以上 |
| 服务类 | 合同估算价 1000 万元及以上 |

其他集团集中采购情形：

- 集团公司重大项目中的工程建设项目，依法必须招标的项目。
- 集团公司重大项目中的生产经营项目，达到本办法第二十七条招标额度的项目。
- 集团公司重大项目包括投资额大于 5 亿元（含）的项目，以及列入集团年度重大项目清单的投资项目。

审查触发：

- 文件金额达到集团集中采购阈值，但文件仅按子公司或下属企业自行采购描述审批、定标、监督或合同签订流程的，应提示审批层级风险。
- 文件出现“自行采购”“由需求部门直接确定”等表述时，应结合金额、类别、是否重大项目核对是否可能规避集中采购。

### 2. 子公司集中采购与自行采购

- 各板块达到招标额度但未达到集团集中采购额度的工程建设项目，以及全部生产经营项目（集团公司重大项目除外），由各子公司按所属行业制定子公司集中采购规模标准。
- 未达到集中采购额度的项目由需求企业自行采购。
- 审查触发：文件未说明采购主体、需求企业、采购层级或审批依据时，应列为“需人工确认采购权限”的复核项。

## 三、必须招标限额与采购方式

### 1. 采购方式分类

- 招标方式包括公开招标、邀请招标。
- 非招标方式包括询比采购、竞争谈判采购、单源直接采购、竞价采购等合规方式。
- 招标限额以下采购项目可采用非招标方式，采购人应根据标的规模、交货/服务/施工期限、供货商选择、采购时机等情况合理选择。

### 2. 生产经营项目必须招标限额

依法必须招标项目按国家法律法规执行。集团各级企业的生产经营项目达到以下限额也必须招标：

| 项目类别 | 必须招标阈值 |
| --- | ---: |
| 生产系统改造和大小修等建设施工类 | 单项合同估算价 400 万元以上 |
| 货物类项目，含不申请软件著作权的信息系统 | 单项合同估算价 300 万元以上 |
| 服务类项目，含日常运行维护等劳务外包 | 单项合同估算价 200 万元以上 |

审查触发：

- 金额达到上述阈值但文件采用询比、竞争谈判、单源、竞价或其他非招标方式，且没有内部审批依据和适用情形说明，应列为重大风险。
- 招标文件将一个整体项目拆成多个低于阈值的包件、标段或合同，且内容高度关联，应提示“化整为零规避招标”风险。
- 200 万元以上服务类项目通常应使用“招标人/投标人/中标人”等招标称呼；若文件仍混用“采购人/供应商”，需结合采购方式判断称呼风险。

### 3. 公开招标与邀请招标

- 招标项目原则上应采取公开招标方式。
- 可选择邀请招标的情形包括：技术复杂、有特殊要求或受自然环境限制，只有少量潜在投标人可供选择；公开招标费用占项目合同金额比例过大；生产经营项目涉及商业秘密等特殊情况，适宜招标但不宜公开招标；法律法规规定不宜公开招标。
- 应该招标的项目拟采用邀请招标或非招标方式（仅限生产经营类项目）采购，应履行内部审批流程。
- 邀请招标应选择不少于 3 家资质、履约能力符合要求且资信良好的潜在投标人，并履行审批手续后发出邀请。

审查触发：

- 邀请招标文件未说明邀请理由、审批手续、受邀单位不少于 3 家、资质和履约能力要求的，应列为缺漏。
- 公开招标项目设置过窄资格、地域、行业、品牌、特定案例或特定技术参数，导致潜在投标人明显不足的，应提示排斥竞争风险。

## 四、招标文件编制与审查要点

### 1. 招标文件关键条款必须清晰

招标文件应对以下关键条款表述清晰明了：

- 资格审查。
- 评标办法。
- 评分权重。
- 评分要素。
- 合同付款。
- 围标串标、弄虚作假、骗取中标资格的赔偿责任，或投标保证金不予退还等责任条款。

审查触发：

- 资格条件、评分项、付款条款、合同草案之间存在不一致，应列为跨章节一致性问题。
- 评分表只有“优、良、中、差”“综合评价”等主观描述，缺少明确分值、客观标准或证明材料，应列为评审可核验性风险。
- 文件未约定围标串标、弄虚作假、骗取中标资格的责任承担或保证金处理，应提示补充。

### 2. 竞争、公平与价格权重

- 招标文件应按鼓励竞争、公平合理原则设置投标人资格门槛。
- 价格权重及计算方法应遵循优质优价原则，避免恶意低价中标。

审查触发：

- 资格门槛明显高于项目实际需要，或要求特定行政区域、本系统、本地业绩、本地分支机构、本集团合作经历、指定品牌型号、唯一专利技术而无合理说明，应提示限制或排斥潜在投标人风险。
- 价格分计算方法可能导致异常低价明显占优，且文件缺少异常低价处理、履约能力核验或风险防控机制，应提示恶意低价中标风险。

### 3. 招标文件审查与发布

- 集团集中采购及集团公司采用招标方式自行采购项目，应按批复采购计划逐级报送招标申请，材料包括招标方案、招标文件、子公司审查意见、招标项目前期分析情况表等。
- 集团采购工作组成员部门会同咨询公司出具审查意见，经集团公司总经理审批并总经理办公会审议通过后，方可联系代理机构发布公告、开展招标。
- 子公司集中采购项目招标文件由子公司组织审查，履行子公司审批程序后方可联系代理机构开展招标。
- 各企业自行采购项目招标文件由招标人自行审查，履行内部审批程序后方可联系代理机构开展招标。
- 发布公告前，代理机构应确认招标人已按制度履行相关审批程序。

审查触发：

- 文件涉及集团集中采购或集团公司采购，但缺少招标方案、前期分析情况表、审查意见、审批或总经理办公会审议信息，应列为流程材料缺漏。
- 文件由代理机构直接发布，但未体现招标人审批完成或代理机构确认审批程序的，应提示发布前置条件风险。

## 五、程序时限、评标定标与合同

### 1. 招标文件发售与提交时限

- 招标文件发出日至投标人提交投标文件截止日应不少于 20 日。
- 资格预审文件发出日至递交资格申请文件的时间应不少于 10 日。
- 公开招标评标结果公示期不得少于 3 日。
- 异议应自收到之日起 3 日内作出答复；答复前应暂停招标投标活动。

审查触发：

- 招标公告、投标人须知、日程表中的发售、答疑、投标截止、开标、公示、异议答复日期不满足上述时限，应列为确定问题或疑似问题。
- 多处日程表、公告、投标须知日期不一致，应列为跨章节一致性问题。

### 2. 评标委员会与定标

- 评标委员会依法独立评标，任何单位或个人不得干预。
- 评标委员会人数为 5 人以上单数，集团集中采购项目原则上不少于 7 人。
- 招标人原则上应选择排名第一的中标候选人为中标人。若不选择第一中标候选人，应说明不符合中标条件的原因，可重新招标或按评标委员会推荐排序依次确定其他候选人为中标人，并报集团公司备案。
- 公开招标评标结果应网上公示，公示期不少于 3 日。

审查触发：

- 文件未明确评标委员会人数、单数要求、回避制度、独立评审、评标报告签字等内容，应提示评标程序不完整。
- 定标条款允许招标人任意确定中标人、议标改价、跳过候选人排序而无书面说明或备案要求，应列为重大风险。

### 3. 中标通知与合同签订

- 中标通知书发出后，招标人不得改变中标结果。
- 中标通知书发出后 30 日内，招标人应组织中标人按照招标文件和投标文件订立书面合同。
- 不得另行订立背离招标文件实质性内容的其他协议。
- 合同谈判和合同签订内容不得背离招标确定的实质性内容。
- 合同签订后 30 日内，采购人应在电子采购平台录入合同信息并上传合同盖章扫描件。

审查触发：

- 合同条款、付款比例、验收节点、服务期限、质保责任与招标公告、投标人须知、技术要求或评分承诺不一致，应列为跨章节重大问题。
- 文件允许中标后另行协商实质性条款，或合同草案留有可改变核心范围、价格、质量、工期、付款的空白，应提示背离实质性内容风险。

### 4. 付款依据

- 采购付款应按照合同签订单位财务管理规定，依据采购合同、采购发票、入库单/验收单、工程结算书及有关证明材料，履行内部审批程序后办理。

审查触发：

- 付款条款未与合同、发票、验收单、入库单、结算材料、内部审批挂钩，应提示付款依据不足。
- 付款条件与验收、交付、质保、发票类型或税率条款不一致，应列为跨章节一致性问题。

## 六、招标失败与非招标采购

### 1. 招标失败处理

- 生产经营项目第一次招标失败后，应分析标段划分、资质和业绩要求、技术性能指标、工期、潜在投标人情况等合理性，以及是否存在专利技术或排他性条款，并采取措施后重新招标。
- 重新招标仍失败后，可继续重新招标，也可视投标人响应情况选择竞争谈判或单源直接采购。

审查触发：

- 文件或补充文件以“二次失败”为由转竞争谈判或单源直接采购，但未体现失败原因分析、调整措施和审批流程，应列为流程风险。
- 招标失败原因可能来自排他性资格、过高业绩、特定技术参数或工期不合理，应提示重新审查资格和技术要求。

### 2. 询比采购

- 采购文件应明确技术要求、采购数量和规格型号或服务内容与标准、报价格式、合同条款、评审方法等事项。
- 原则上公开方式；确需邀请方式的，受邀单位名单应履行内部审批。
- 邀请询比应向 3 家及以上潜在供应商发出邀请。
- 评审小组由采购人代表、专业技术人员和专家共 3 人及以上单数组成。
- 公开询比提交响应文件不足 2 家，应重新组织；邀请询比提交响应文件不足 3 家，应重新组织。
- 公开方式成交结果应在电子采购平台公告。

审查触发：

- 询比文件缺少评审方法、报价格式、合同条款、技术标准或响应文件最低家数要求，应提示。
- 邀请询比少于 3 家或未体现受邀名单审批，应提示。

### 3. 竞争谈判

- 采购文件应明确谈判程序、谈判内容、合同草案条款及成交评定标准。
- 可通过电子采购平台公告或邀请 2 家及以上符合资格的供应商参加。
- 谈判小组由采购人代表、专业技术人员和专家共 3 人及以上单数组成。
- 采购文件有实质性变动的，应以书面形式通知所有参加谈判的供应商。
- 多轮报价应保证每个供应商得到均等机会，并要求所有参加谈判供应商在规定时间内提供最后报价及有关承诺。
- 若提交响应文件供应商不足 2 家，应变更受邀单位名单后重新组织；重新组织仍失败并履行审批后，可选择单源直接采购。

审查触发：

- 竞争谈判文件没有谈判程序、最后报价、书面通知实质性变动、均等机会或成交标准，应提示。

### 4. 单源直接采购

- 应充分论证合理性和必要性，在保证质量和双方商定价格合理基础上进行。
- 适用情形包括不可替代专利、专有技术、垄断性行业或供不应求产品；涉及商业秘密或特殊原因导致只能从唯一供应商处采购；不可预见紧急情况；原标的后续维修、零配件、更换或扩充必须向原供应商采购；为保证一致性或服务配套要求需要向原供应商采购；其他非招标方式二次失败并履行审批。
- 采购文件应明确采购内容与数量、技术与商务要求、合同条款与格式、报价格式与要求、评定成交标准及谈判日程安排。
- 谈判小组由采购人代表、专业技术人员和专家共 3 人及以上单数组成。

审查触发：

- 单源采购文件未说明唯一性、不可替代性、紧急性、原厂配套或二次失败依据，应列为重大风险。
- 仅以“历史合作良好”“熟悉项目情况”“领导指定”“集团内部单位”作为单源理由，缺少市场化公允价格、审批和必要性论证，应提示。

### 5. 竞价采购

- 适用于采购需求明确、技术规格标准统一、标准化程度高、采购频次不高、价值较低且可以价格作为唯一竞争依据的项目。
- 公告应明确物资名称、规格、型号、技术要求、单位、数量、交货方式、竞价类型、评定成交方式、开始截止时间等。
- 原则上公开方式；确需邀请方式的，受邀单位名单应履行内部审批。
- 报价供应商少于 3 家时，竞价采购无效，应重新竞价；重新组织仍失败，履行审批后可选择单源直接采购。

审查触发：

- 竞价项目存在复杂服务、定制开发、复杂施工或质量方案差异，但仍以价格作为唯一竞争依据，应提示采购方式不匹配。

### 6. 非招标方式时限

- 采用经评审的最低价法，采购文件发出之日至递交响应文件截止之日不得少于 3 日。
- 采用综合评审法，采购文件发售/发布时间不得少于 5 日，采购文件发出之日至递交响应文件截止之日不得少于 10 日。

审查触发：

- 非招标采购文件的公告、发售、递交截止日期不满足上述时限，应列为时限风险。

## 七、前期分析情况表与市场竞争审查

招标项目前期分析情况表应关注：

- 项目名称。
- 招标范围。
- 实施期限。
- 项目概算。
- 近三年类似项目招标情况分析，不少于 3 个；包括招标范围、资格条件设置、开评标情况、否决情况、第一至第三中标候选人及报价。
- 潜在投标人情况，不少于 4 家；包括注册资本、经营范围、资质等。
- 本次招标项目投标人资格条件设置情况，包括业绩和资质。

审查触发：

- 文件中的资格条件、业绩门槛、资质要求与前期分析情况表不能相互支撑，应列为资格条件合理性风险。
- 潜在投标人不足 4 家、历史类似项目不足 3 个，或资格条件设置导致有效竞争不足，应提示竞争不充分风险。
- 技术指标、业绩要求、工期或标段划分导致第一次招标失败，应要求复核前期分析和排他性条款。

## 八、纪律、禁止行为与责任条款

### 1. 禁止规避招标和不公平竞争

高风险行为包括：

- 应采用公开招标而未采用。
- 将必须招标项目化整为零、规避招标。
- 擅自提高采购标准。
- 与供应商违规串通，增加采购成本。
- 擅自取消投标人资格。
- 以不合理条件限制、排斥潜在投标人，致使不公平竞争。
- 在集中采购确定的供应商以外另选供应商签订合同。
- 未履行合同审批程序，擅自对外签订采购合同。

审查触发：

- 文件出现指定供应商、指定品牌、限制外地或系统外供应商、排斥新供应商、资格条件过窄、临时取消资格、集中采购之外另行签约等内容，应列为重大合规风险。

### 2. 保密、回避和监督

- 招标工作人员与投标人有利害关系的，应执行回避制度。
- 不得泄露标底、投标人名称和数量、评标定标人员组成和身份、评审情况、中标候选人推荐顺序等招标工作秘密。
- 招标、开标、评标、定标、合同签订等环节应接受全过程监督。

审查触发：

- 文件未明确回避制度、保密要求、评标纪律或监督机制的，应提示。
- 文件在开标前披露不应公开的信息，或安排可能泄露评标专家身份、投标人名单、评审情况的流程，应列为保密风险。

## 九、智能体输出要求

审查报告引用本依据时，优先使用以下问题类型：

- 采购方式/招标限额风险。
- 集中采购/审批层级风险。
- 电子采购平台使用风险。
- 招标文件关键条款缺漏。
- 资格条件限制竞争风险。
- 评审办法不可核验风险。
- 公告、投标、资格预审、公示或异议时限风险。
- 评标委员会、定标和中标候选人排序风险。
- 合同条款背离招标实质性内容风险。
- 非招标采购适用情形或程序风险。
- 单源采购必要性和唯一性论证不足。
- 前期分析情况表支撑不足。
- 付款、验收、发票、结算和审批联动不足。

当招标文件片段缺少项目金额、采购类别、采购主体、采购方式或审批层级时，不要直接判定违规，应标注为“需跨章节复核”或“需人工确认”，并说明需要补充核对的信息。
