# “一本高校”口径与获取方法（动态、按省份和年份）

- 资料性质：动态核验方法，不存在全国统一、永久不变的“一本高校名单”。
- 本地核对日期：2026-06-22。
- 教育部阳光高考平台：https://gaokao.chsi.com.cn/
- 教育部全国高等学校名单入口：https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A03/

## 为什么不保存一份全国“一本高校名单”

“一本”通常指某所高校或某个专业在特定省份、特定招生年份被安排在本科第一批次招生。它不是学校永久、全国统一的行政等级。同一学校可能在不同省份、不同年份或不同专业使用不同批次；不少省份还已合并本科批次。因此，把“学校名称 -> 一本/二本”做成静态全国表会产生大量误判。

## 招聘审查所需字段

要核验候选人所称“一本”，至少需要：

- 生源省份或参加高考的省级行政区。
- 招生年份。
- 学校完整名称及校区。
- 专业名称或专业组。
- 当年录取批次；实行批次合并的省份则记录实际本科批次和投档情况。

缺少上述字段时，应写“无法按省份和招生年份确认一本口径”，不得直接判定候选人虚假或不符合条件。

## 稳定查询流程

1. 先在教育部全国高等学校名单中确认学校主体和标准名称，排除独立学院、继续教育学院或名称相近学校。
2. 在教育部阳光高考平台查询学校及招生章程、招生计划。
3. 进入候选人生源省份教育考试院或招生考试机构官网，查询对应年份的招生计划、批次说明和投档/录取数据。
4. 保存省份、年份、专业、批次、来源 URL 和访问日期；网页更新时可复核历史快照或官方 PDF。
5. 若当年已合并本科批次，不再输出“一本/二本”结论，只记录实际批次和投档证据。

## 建议记录格式

```text
学校：<完整学校名称>
校区/办学主体：<如有>
生源省份：<省份>
招生年份：<YYYY>
专业/专业组：<名称>
当年批次：<本科一批/本科批/其他>
结论：<可确认/不可确认/批次已合并>
官方来源：<URL>
访问日期：<YYYY-MM-DD>
```

## 审查约束

- 不把当前招生批次倒推为候选人入学当年的批次。
- 不把学校本部与独立学院、分校、合作办学项目混为一谈。
- “一本”仅在岗位要求明确、合法且与岗位相关时作为筛选参考；否则只作教育背景说明。
