# 高校层次与排名审查参照

本目录是 `resume-review` 和 `batch-resume-review` 共用的高校参考资料。

## 文件分类

- `985工程高校名单_教育部.md`：39 所固定历史名单。
- `211工程高校名单_教育部.md`：112 个教育部历史工程条目及名称口径。
- `双一流建设高校名单_第二轮_2022.md`：2022 年第二轮 147 所建设高校，必须带年份使用。
- `一本高校口径与获取方法.md`：按生源省份、招生年份、学校和专业动态核验，不维护误导性的全国静态表。
- `世界大学排名官方入口与更新规则.md`：官方动态入口、版次字段和合法快照方法。

## 更新规则

1. 985/211 只修正来源、别名或录入错误，不新增学校。
2. 教育部发布新一轮双一流名单时，新建带轮次和年份的文件，保留旧版。
3. 一本数据如需落地，按 `省份_招生年份` 单独保存，并记录省级考试机构来源。
4. 世界排名快照必须带机构、版次年份和获取日期；不要覆盖历史快照。
5. 每次更新后运行高校参考数据测试和两个简历智能体测试。

## 模型使用原则

名单用于证据核对，不是自动歧视或替代能力评价的标签。岗位未明确要求学校层次时，智能体不得仅凭 985/211/双一流或排名筛除候选人。
