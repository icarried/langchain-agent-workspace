# 智能简历筛选规则

本规则来自 FastGPT 导出工作流“智能简历筛选”的有效经验，但不照搬其单一长提示词。工作区实现采用“岗位配置 -> 简历解析 -> 硬性/淘汰条件判断 -> 量化评分 -> 排行榜报告”的 LangGraph 工作流。

## 输入参数

- 职位名称、所属部门、职级范围。
- 硬性条件：候选人必须满足的学历、专业、经验或技能要求。
- 优先条件：命中后加分的条件。
- 淘汰条件：命中后直接不推荐或淘汰的条件。

## 筛选流程

1. 基础条件过滤：检查硬性条件和淘汰条件。
2. 量化评分：教育背景、工作经验、技术能力、项目成果和软性素质。
3. 风险检测：提示词注入、时间线异常、频繁跳槽等线索。
4. 排行榜输出：按推荐状态和分数生成候选人排序。

## 输出要求

- 不得把命中淘汰条件的候选人写成推荐。
- 硬性条件不完整者必须显示缺失项。
- 排行榜需要包含姓名、分数、优势标签、风险提示和推荐意见。
- 分数是初筛辅助信号，不替代人力面试和背景核验。
