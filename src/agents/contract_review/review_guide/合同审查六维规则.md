# 合同审查六维规则

本规则来自 FastGPT 导出工作流“合同审查大师”的有效经验，但不照搬平台节点。工作区实现采用“表单上下文 + 六维审查 + 评分评级 + 修改建议”的 LangGraph 工作流。

## 输入上下文

- 委托方角色：甲方、乙方或其他合同利益相关方。
- 合同类型：采购、服务、租赁、建设工程、技术开发、合作协议等。
- 交易背景：交易目的、履约方式、付款安排、关键商业诉求和已知争议。

## 六个审查维度

1. 主体合法性审查：签约主体资格、授权权限、经营范围、特殊资质、分支机构签约资格、资信和履约能力线索。
2. 内容合法性审查：标的合法性、强制性规定、审批登记或招投标程序、无效免责、限制竞争和知识产权归属。
3. 条款完备性与明确性审查：主体、标的、数量、质量、价款、履行、验收、违约责任、争议解决、通知和附件。
4. 风险防控与实用性审查：违约责任可计算、补救措施、管辖或仲裁机构明确、保密、知识产权、变更、不可抗力和证据留存。
5. 形式与表述规范审查：结构顺序、编号引用、定义一致性、法律术语、模糊词、签署页、盖章、附件和生效条件。
6. 履行与终止审查：进度管理、验收付款、通知义务、单方解除权、终止情形、终止后结算返还和后合同义务。

## 评分口径

- 法律合规性 35 分：主体、内容和程序合法性。
- 风险控制 40 分：违约责任、争议解决、保密、知识产权、解除终止和履约监督。
- 条款清晰度 25 分：核心条款完备性、表述明确性、结构和签署形式。
- A 级，90 分及以上：可签署。
- B 级，75-89 分：建议修改后签署。
- C 级，60-74 分：重大风险需重构。
- D 级，60 分以下：不建议签署。

## 输出要求

- 所有问题必须引用合同元素编号或片段位置。
- 没有合同证据时写“待补充资料”，不得虚构条款。
- 修改建议应说明保留、删除、补充或改写方向。
- 结论必须面向委托方角色给出，不作中立泛泛评价。
- 报告末尾必须声明：本报告为辅助审查，不替代执业律师正式法律意见。
