# 人工智能开发工程师岗位要求（测试夹具）

## 专业

计算机科学与技术、软件工程、自动化、人工智能、电子信息工程等专业。

## 工作职责

1. 协助开展工业场景 AI 算法支撑，参与机器学习、计算机视觉算法方案设计、调试和落地。
2. 参与工业视觉、NLP 诊断项目需求调研、方案梳理和交付。
3. 参与 RAG、提示工程、模型微调、推理加速和量化优化，适配工业边缘设备。
4. 完成数据清洗标注、模型训练、边缘或云端部署及监控。
5. 参与多模态、高并发、强化学习等方案调研和性能优化。
6. 撰写技术文档，参与跨团队评审、联调和现场支持。

## 任职要求

1. 本科或硕士及以上学历，熟练掌握数据结构、算法设计、计算机网络等知识。
2. 有软件开发或项目实践经历，熟悉至少一种编程语言，如 Python、Java。
3. 熟练掌握 AI 领域算法，对大模型、机器学习、深度学习或强化学习有实操经验。
4. 了解软件开发全流程，熟悉工业互联网架构基础，对物联网数据采集、工业云平台有一定认知。
5. 学习能力强，善于沟通，具备团队协作精神。
