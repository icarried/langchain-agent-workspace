# 学历学制与教育路径判断

- 资料性质：基于学习时间的初筛线索，不是仅凭年限作学历真伪判断的规则。
- 本地核对日期：2026-06-22。

## 本科阶段

- 国内普通全日制本科常见学制为四年，部分医学、建筑等专业可能为五年或更长。
- 专升本常见路径是先完成专科阶段，再进入本科阶段学习；简历可能只列本科阶段，也可能合并列出。两年或三年本科记录只能提示核对前置学历，不能直接认定为专升本。
- 三年制本科在部分境外教育体系中属于正常学制；还可能存在转学分、第二学位、提前毕业等情况。
- 非全日制、成人教育、网络教育等学习年限可能弹性变化，应核对学习形式和证书，不用四年标准直接否定。

## 硕士阶段

- 国内硕士常见为两年至三年，三年制较常见，部分专业硕士可能为两年或两年半。
- 英国、香港、新加坡等教育体系存在正规一年制授课型硕士。不得仅凭一年学制使用“水硕”等贬损标签或直接降为不合格。
- 对短学制硕士，应重点评价学历认证、录取背景、课程数量和强度、论文/毕业项目、实习、科研成果及岗位相关性。
- 本硕时间重叠、硕士开始早于本科毕业或工作与全日制学习明显重叠时，应列为复核项并询问联合培养、交换、实习、提前录取或填写错误。

## 筛选和评分边界

- 最低学历只在 JD 明确提出时作为硬性筛除条件。
- 全日制要求也必须由 JD 明确提出；简历未写学习形式时标记复核，不自动判为非全日制。
- 学制异常、培养类型和时间线问题通常进入附加复核项，候选人仍参与评分排名。
- 只有简历明确显示最高学历低于 JD 最低学历，或明确显示学习形式与 JD 硬性要求相反时，才可基于学历条件筛除。
