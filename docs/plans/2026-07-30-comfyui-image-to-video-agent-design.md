# ComfyUI 图生视频智能体设计

## 需求与约束

新增独立模型 `comfyui-image-to-video-agent`，基于用户提供的 LTX 2.3 I2V API工作流生成视频。输入必须包含单张参考图片和文字指令；文字可声明尺寸、时长、FPS和seed。时长硬上限15秒，FPS默认25且最多30，尺寸采用常用白名单，最大档位为横竖屏1080p。服务继续沿用统一网关、隔离worker、ComfyUI轮询和结构化视频元数据协议。

## 架构决策

采用“确定性参数层 + 视觉LLM提示词层 + 受控工作流渲染”三层结构。确定性层解析显式字段和常见中文/英文表达，显式字段优先，并在任何外部调用前执行Pydantic范围和尺寸白名单校验。视觉Qwen3.5同时读取首帧与文字，只输出 `rewritten_prompt`，不能输出或覆盖技术参数。若改写失败，使用原始指令继续生成并在结果中标记 fallback。内置工作流自己的提示词增强开关固定关闭，避免双重改写。

输入图片经共享远程附件策略读取，校验真实格式和字节上限，再用随机任务文件名上传至 ComfyUI `/upload/image`；工作流只接受该接口返回的安全相对路径。输出继续作为内部源产物交给调用平台持久化。

## 失败模式与验证

- 缺少图片、超过15秒、超过FPS限制或尺寸不在白名单：提交GPU前返回400。
- 图片下载、格式或大小错误：返回安全错误，不记录完整签名URL或Base64。
- 提示词LLM不可用：回退原指令，不阻断生成。
- ComfyUI上传、工作流校验或执行失败：转换为脱敏502/流式可读错误。
- ComfyUI等待超时：返回任务状态，不取消已经提交的任务。

测试覆盖自然语言参数、显式覆盖、硬限制、工作流节点白名单、图片上传、dry-run、非流式、SSE、网关注册和Compose端口隔离。
