# Bundled preview fonts

This directory bundles Noto Sans SC and Noto Serif SC variable fonts under the SIL Open Font License 1.1. They are redistributable Linux preview substitutes for the font names written by the formatting API.

They are not the proprietary 方正小标宋简体、仿宋_GB2312 or 楷体_GB2312 font files. The accompanying fontconfig file maps those requested family names to the closest bundled serif or sans-serif substitute for Linux/WPS/LibreOffice preview. Exact typography still requires organization-licensed fonts on the final review workstation.
